# 手动验收清单

使用专门的测试笔记，避免把个人正文或截图提交到 GitHub。

- [ ] 构建和签名通过，Finder 和 Dock 显示暖橙便笺图标。
- [ ] 普通模式和 `--demo` 分别启动，缓存彼此隔离。
- [ ] 新建本地笔记，修改标题及正文，重开仍保留。
- [ ] 请求 Notes 授权；拒绝时显示可理解的错误，缓存继续可读。
- [ ] 读取文件夹与标题，组合搜索/筛选，勾选后仅导入所选。
- [ ] 手动刷新来源后，来源快照更新，本地修改保持。
- [ ] 拖动两条分隔线，三栏实时调宽，重开恢复布局。
- [ ] 创建待办，圆圈只切换状态，文字可编辑，只有行尾把手启动排序。
- [ ] 按住把手缓慢下拖、停住、反向上拖，检查不闪烁；Esc 还原，松手后重开顺序保持。
- [ ] 输入数字、大小写字母和罗马列表，回车续号、空项退出、Tab/Shift-Tab 缩进。
- [ ] 创建 3×3 表格，测试行列重排、单元格交换、Tab 换格和追加行列。
- [ ] 选中文字叠加粗体/下划线、字体、字号、颜色和高亮；测试段落对齐及行距。
- [ ] 富文本重开后样式保留，回车拆段与退格合并不会丢失文字。
- [ ] 插入命名链接，测试自动 URL 与 ⌘点击，检查无效地址报错。
- [ ] 撤销/重做编辑及排序，测试长中文、emoji、输入法组合输入。
- [ ] 检查来源预览、纯文本及原文差异，确认未改写 Apple Notes。

自动检查通过不能替代真实设备上的拖动体验、权限对话框和导入保真度验收。
