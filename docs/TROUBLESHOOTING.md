# 故障排查

## 自动化权限被拒绝（-1743）

从 Finder 打开构建后的 NativeNotes.app，点击“读取来源”。进入系统设置 → 隐私与安全性 → 自动化，允许 NativeNotes 控制备忘录。

没有 NativeNotes 条目时，先确认实际启动的是打包应用；条目通常在系统收到请求后出现。若曾拒绝且无法再次触发，可退出应用，在终端重置**仅此应用**的 Apple Events 授权，再重新打开并点击读取：

```sh
tccutil reset AppleEvents local.NativeNotes.Milestone1
```

这会清除此应用的自动化授权选择，之后需重新允许。不要重置全局权限，也无需开启完全磁盘访问。开发环境无法请求授权时，使用 `--demo` 验证本地功能，真实导入另行验收。

## 读取失败或列表为空

- 打开 Apple Notes，确认账户、文件夹、笔记已在本机加载。
- 锁定笔记或未下载内容可能无法读取；失败时已有缓存仍可查看。
- 保留错误编号及文本，使用最新源码重新构建。旧版 -1700 账户对象转换错误已修复，反复改授权不能解决脚本类型错误。

## 表格、图片或勾选状态缺失

AppleScript 返回的 HTML 可能缺少结构。切换“来源预览”和“来源纯文本”对照，或在 Apple Notes 中打开原文。刷新不保证补回脚本接口未提供的数据；普通列表无法可靠恢复原始勾选状态。

## 富文本按钮不可用

先点击正文或列表文字，或选中一段文字。表格单元格不接入这组工具。字体、字号及颜色未选中文字时用于后续输入；行距和对齐作用于段落。

## Finder 图标未更新

确认打开的是最新构建的 `.app` 而非裸可执行文件或旧快捷方式。构建脚本已复制多尺寸 icns 并登记应用。退出应用，关闭后重新打开所在 Finder 窗口；Dock 旧快捷方式可移除后重新添加。避免在签名完成后额外写入自定义 Finder 图标属性，以免破坏签名验证。

## 保存失败、冲突或损坏文档

不要删除原文件。保留完整数据目录备份，先使用“另存完整副本”保存未写盘内容，再处理版本冲突或磁盘问题。手动刷新来源不能修复本地 JSON，也不会替换其内容。
